# Property Intel

## What This Is

Property Intel is a map-based property intelligence tool for rent-to-rent investors in the UK. It identifies investment hotspots for Serviced Accommodation (SA) and House in Multiple Occupation (HMO) by analyzing booking data and property listings from platforms like OpenRent, Zoopla, and SpareRoom, providing automated profit analysis for potential investments.

## Core Value

Empower rent-to-rent investors to quickly identify high-profit property investment opportunities in the UK market through data-driven hotspot analysis and automated profit calculations.
